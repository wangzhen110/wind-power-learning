# 风电标准学习平台

把三套风力发电行业标准课程整合为一个**统一学习网站**，登录账号后按「账号 + 课程」独立保存学习进度。

## 在线地址

https://wangzhen110.github.io/wind-power-learning/

## 包含课程

| 课程 | 标准号 | 章节 | 选择题 | 填空题 | 知识库 |
|---|---|---|---|---|---|
| 风机电梯 | GB/T 46154—2025《风力发电机组用电梯制造与安装安全规范》 | 14 章 | 330 | 74 | 585 条款 + 36 规范 |
| 内附件 | NB/T 11773—2025《风力发电机组内附件技术规范》 | 9 章 | 216 | 81 | 123 条款 + 82 规范 |

每门课程均含五种模式：**讲解 / 答题 / 填空 / 模拟考试 / 统计**，出处可点击查看课程内知识库条款原文。

## 模拟考试（自动组卷）

- **入口**：课程页左侧边栏「模拟考试」按钮（窄屏时在顶部移动端导航栏），与讲解/答题/填空/统计并列。
- **组卷配置**（进入考试视图默认显示配置面板）：
  - 选择题数量：默认 20，范围 1-100，自动上限为当前章节范围内的选择题总数；
  - 填空题数量：默认 5，范围 0-50（0 表示不考填空），自动上限为当前章节范围内的填空题总数；
  - 章节范围：「全部章节」或指定单章；
  - 考试时长：默认 30 分钟，范围 5-180 分钟，倒计时归零自动交卷。
  - 点「开始考试」后按配置随机抽题（Fisher-Yates 洗牌），选择题在前、填空题在后，题号连续；每次组卷题目与顺序都不同。
- **考试过程**：顶部倒计时（mm:ss）+ 题号进度，上一题/下一题/标记不确定题，底部答题卡可跳转；交卷时若有未答题目会弹窗确认，未答按错误计。
- **判分与结果**：交卷后逐题判分（选择/判断/多选与答题模式同逻辑，填空用多可接受答案归一化匹配），结果页展示百分制总分、答对/总题数、正确率、用时，以及每题的你的答案/正确答案/对错/解析/出处。
- **成绩查询**：配置面板与结果页均有「查看历史成绩」入口；成绩按「账号 + 课程」独立保存在 `unified_v1_<课程>_<账号>_exam`，按时间倒序展示，可点任意一条回看该次答题详情，也可一键清空（带二次确认）。

## 账号体系

- **注册**：首次使用点「注册账号」，输入账号（字母/数字/下划线）、昵称、密码即可
- **登录**：之后用账号 + 密码登录
- **数据独立**：每个账号的答题记录、错题、标记、填空进度完全独立存储（`unified_v1_<课程>_<账号>_*`），互不干扰
- **退出**：课程页顶栏「退出」或门户右上角「退出登录」
- **密码安全**：密码不存明文，使用加盐 SHA-256 哈希后保存

### 说明与限制

- 账号数据保存在**当前设备的浏览器**（localStorage），换电脑/手机时需用课程内「导出 / 导入进度」迁移（导出文件名含账号名，导入后合并或覆盖）
- 纯前端静态实现（GitHub Pages 无服务器），密码校验在本机完成，适合内部培训、多人共用电脑等场景；如需云端账号同步需另接后端服务

## 技术结构

```
index.html          登录页 + 课程门户 + 课程学习（单页）
app.js              统一逻辑（账号 + 课程路由 + 讲解/答题/填空/模拟考试/统计 + 知识库）
style.css           样式
data/meta.js        三门课程题量元数据
data/<课程>/ch*.js  各章讲解与题库
data/<课程>/fill.js 填空题库
data/<课程>/kb.js   课程内知识库
sw.js / manifest.json  PWA 离线支持
```

## 本地运行与验证

- 直接双击 `index.html` 可用（浏览器 file:// 下 localStorage 亦可）
- 推荐本地起 HTTP 服务体验完整 PWA：`node _verify/static_server.js` 后访问 http://127.0.0.1:8765
- 验证脚本：
  - `node _verify/verify_unified.js`（jsdom 功能验证，含账号隔离）
  - `node _verify/verify_browser.js`（Edge 真浏览器全流程 + 多视口布局）

## 修改课程内容

改 `data/<课程>/chXX.js`（题目/讲解）或 `fill.js`、`kb.js` 后，重新提交推送即可；如改动 PWA 缓存清单，需同步递增 `sw.js` 中 `CACHE_VERSION`。

### 出处弹窗匹配逻辑

正文规范链接（`.std-link`）点击后通过 `kbLookup()` 匹配知识库条目，匹配层级依次为：

1. **精确匹配**：`kbMap()` 按课程映射规则精确查找 `KB.standards`
2. **自引用**：正文引用当前课程标准自身编号时，显示「本课程标准」提示
3. **归一化索引**：`stdIdx` 按 `stdNorm()`（去空格、统一破折号、大写）匹配
4. **年份兼容**：查询侧与键侧均剥离末尾 `—YYYY` 后二次匹配（正文带年份/键不带年份，或反之）
5. **系列号展开**：合并系列键（如 `GB/T 3480.1/.2/.3/.5`）自动展开子编号别名；`（所有部分）`后缀键（如 `GB/T 3880（所有部分）`）支持基数与子部分前缀匹配

新增规范条目时统一录入不带年份的规范号到 `KB.standards`，年份变体由匹配层自动处理。
